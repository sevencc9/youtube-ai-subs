# 自用 AI 双语字幕扩展（初版）

基于 https://github.com/Gythiro/yt-dual-subs ，保留原项目 MIT 许可证。

## 安装
1. Chrome/Edge 打开扩展管理页，开启开发者模式。
2. 点击“加载已解压的扩展程序”，选择本目录（包含 manifest.json）。
3. 打开扩展设置，配置 DeepSeek 或其他自定义兼容 API、模型与密钥，选择自带 API 翻译引擎。
4. 勾选设置页顶部“AI 智能断句与翻译（个人版）”。
5. 刷新有字幕的 YouTube 视频。处理期间沿用原字幕，已处理的完整句子逐批替换显示，页面右下角显示进度或错误。

启用后整条字幕发送至所选 API，按服务商规则计费；原有实时翻译也可能同时产生请求。不开启则沿用上游行为。API 密钥沿用上游本地保存机制。

## 实现与限制
- 每批最多 240 个单词、10000 字符；模型返回连续单词编号与译文，程序重建原文与时间轴。
- 严格拒绝缺漏、乱序、重叠、越界及空译文；失败保留原有字幕，控制台显示提示。
- 不改写原文，不修复原文标点；支持原片段内部按单词切分。非末批最后一句保留至下一批，避免强制截断。词级时间按原字幕时长均分估算，不是音频强制对齐。
- 本地缓存按模型、API 地址、目标语言、字幕内容隔离，最多 200 批；设置页可清除。
- 暂无 Whisper、AI 结果专用导出。语义边界仍受模型质量影响。
- 已完成 JavaScript 语法检查与分组校验测试，尚未完成真实浏览器/API 联调。

测试：`node --test tests/ai-segments.test.cjs`

## 3.7.2 修复
- 修复已完成句子前缀被整批覆盖校验误拒绝的问题（此前可能导致处理停止）。
- 未处理区域按剩余单词重建，避免交界处重复原字幕前半段；译文显示“AI 正在处理此段…”而非混用旧译文。
- 对 of、with 等明显悬空的英语句尾进行一次模型纠正并重新翻译；仍不合格则提示失败。纠正可能产生额外 API 请求。

## 3.7.3 错误诊断与格式纠正
- 分别显示认证、余额、限流、网络、JSON、字幕编号覆盖和句子边界错误；不再统一提示检查密钥。
- JSON 或编号覆盖失败时同样自动纠正一次；认证和网络错误不作为格式错误重试。
- 错误消息只使用固定文案，不传递密钥或原始服务商响应。
- 16 项测试通过（含模拟错误响应及纠正流程）；尚无本次真实失败的服务端错误，不能确定截图对应的具体原因。
